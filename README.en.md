## Profile

I design and build backend systems, from service boundaries and data models to APIs, integrations and deployment.

I combine architecture work with hands-on implementation. My focus is database performance, reliable transaction processing, observability and predictable delivery.

## Engineering focus

**Architecture.** Service boundaries, microservices, distributed and event-driven systems.

**Performance.** SQL optimization, caching, queues and idempotent transaction processing.

**Operations.** Containers, CI/CD, monitoring, logging and incident diagnosis.

**Integrations.** Payment systems, KYC, CRM, Telegram and WhatsApp.

## Public code

Open-source tools, integrations and product experiments.

### [Chronograph](https://github.com/localmiracle/chronograph)

**Go · tracing · CLI**

A tool for collecting and analyzing span events. Includes duration filtering, graph pruning, and JSON or DOT output. The repository contains a library and a CLI with a demonstration scenario.

### [GREEN-API Demo](https://github.com/localmiracle/green-api-demo)

**Node.js · TypeScript · Express**

A WhatsApp integration demo using GREEN-API. Separates controllers, use cases and the HTTP service; a web interface lets you inspect settings and send messages or files.
